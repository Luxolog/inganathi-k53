# Road-sign question diagrams

The learner test is wired to the supplied Inganathi questionnaire artwork.

- Questions **73–178** each have a `diagramImages` entry in `clean_questions.json`.
- Expected files are `q073-1.png` through `q178-*.png`.
- The companion asset package contains **112 PNG files** extracted from the supplied DOCX questionnaire and converted to PNG.
- Some source questions contain two images; those use `-1.png` and `-2.png`.

## Upload location

Place the PNG files in this exact repository folder:

`assets/road-signs/`

The website will automatically display the matching diagram(s) when the question appears.

The question wording, answer options and correct-answer indexes are not changed by the diagram wiring.
